## 🌍 Giới thiệu Dự án / Project Overview

### 🇻🇳 Tiếng Việt
**WWII Declassified Dossier** là một ứng dụng web slide thuyết trình tương tác điện ảnh, đưa người xem du hành ngược thời gian về giai đoạn Chiến tranh Thế giới thứ Hai (1939 – 1945). Được thiết kế theo ngôn ngữ mỹ thuật của một **"Hồ sơ Quân sự Giải mật" (Declassified War Dossier)**, ứng dụng tái hiện không khí thời chiến thông qua tông màu giấy cổ (*Aged Parchment*), kim loại quân sự (*Munitions Slate & Military Olive*), dấu mộc đỏ niêm phong (*Classified Red*), và phụ kiện ngàm đồng (*Vintage Brass Rivets*).

Dự án gồm 20 slide với đầy đủ các mốc sự kiện khốc liệt: từ Cỗ máy thời gian, Cuộc tấn công Trân Châu Cảng, Khúc quanh Stalingrad, Cuộc đổ bộ Normandy (D-Day), Trận chiến Berlin đến Đài tưởng niệm và Bài học về giá trị của Hòa bình.

### 🇬🇧 English
**WWII Declassified Dossier** is an interactive, cinematic web presentation deck that transports viewers back to the crucible of World War II (1939–1945). Styled as a top-secret **"Declassified Military Memorandum"**, the presentation features an authentic wartime aesthetic: aged parchment, dark munitions slate, military olive cardboards, blood-red classified stamps, and weathered brass hardware brackets.

Featuring 20 meticulously structured slides, it covers pivotal historical milestones: the Time Machine Intro, the Surprise Strike on Pearl Harbor, the Frozen Ruins of Stalingrad, Operation Overlord (D-Day), the Fall of Berlin, and the Solitary Memorial to Human Resilience and Peace.

## ✨ Các Tính năng Nổi bật / Key Features

- 🕰️ **Cỗ máy Thời gian Tương tác (Interactive Time Machine Intro)**: Kim đồng hồ chuyển động ngược chiều kim đồng hồ trên nền hình ảnh lịch sử liên tục, tua nhanh qua các thời đại (Ai Cập, Phục Hưng, Thập niên 1920) trước khi dừng lại ở giai đoạn 1939–1945.
- 🎬 **Video Tư liệu Lịch sử Toàn cảnh (Archival Cinematic Overlays)**:
  - Tích hợp tại **Slide 9 (Pearl Harbor)**, **Slide 12 (Stalingrad)**, và **Slide 13 (Normandy D-Day)**.
  - Tự động chạy khi chuyển bước (`autoPlay`), ẩn thanh điều khiển, bo viền đen vintage với 4 ngàm đồng giống khung ảnh lưu trữ.
  - Phủ lớp màu **Sepia vintage 1940s** kết hợp hiệu ứng tối 4 góc (*vignette*) và màng phim cổ (*scanlines*).
  - Hậu cảnh phía sau tự động làm mờ và tối (*backdrop blur & dim*), cùng hiệu ứng chuyển cảnh *fade in / fade out* mượt mà.
- 🎙️ **Presenter Console & Đồng bộ Đa thiết bị (Dual-Screen & Mobile Remote)**:
  - Chế độ Thuyết trình viên chuyên nghiệp mở ở tab riêng biệt hoặc điều khiển từ điện thoại thông minh qua **mã QR**.
  - Đồng bộ hóa 2 chiều siêu tốc (<1ms) giữa màn hình chiếu chính và bảng điều khiển qua `BroadcastChannel` và `localStorage`.
  - Tích hợp đồng hồ bấm giờ thuyết trình (Stopwatch), kịch bản chi tiết (Script Snippet), từ vựng trọng tâm (Key Vocabulary), và xem trước slide tiếp theo.
- 🖼️ **Phòng Trưng bày Ảnh Lưu trữ (Declassified Archival Galleries)**: Khung ảnh tư liệu lịch sử có thể phóng to kiểm tra chi tiết, kèm nguồn trích dẫn lưu trữ chính xác.
- 🎵 **Nhạc Nền Tưởng niệm (Memorial Soundtrack)**: Âm hưởng hào hùng và bi tráng giúp tăng chiều sâu cảm xúc cho buổi thuyết trình.

## 🕹️ Hướng dẫn Sử dụng Chi tiết / Detailed User Guide

### 1. Chế độ Toàn màn hình (Fullscreen Mode)
- **Cách bật**: Nhấn phím `F` trên bàn phím hoặc nhấp vào biểu tượng **Fullscreen** (phóng to) ở góc phải thanh Header.
- **Hỗ trợ Fallback**: Tự động nhận diện và kích hoạt chế độ toàn màn hình bằng CSS nếu trình duyệt hoặc thiết bị di động chặn Fullscreen API gốc.
- **Cách thoát**: Nhấn lại phím `F` hoặc phím `ESC`.

### 2. Ghi chú Thuyết trình & Màn hình Presenter Console

#### A. Xem nhanh Ghi chú trên Màn hình chính (Speaker Notes Modal)
- Bấm phím `N` hoặc nhấp vào nút **Notes** trên Header.
- Cửa sổ hồ sơ ghi chú sẽ xuất hiện, hiển thị thời lượng chuẩn (*Timing*), gợi ý diễn đạt (*Cue*), và từ khóa trọng tâm mà không làm gián đoạn slide.
- Nhấn `ESC` hoặc bấm nút `✕` để đóng.

#### B. Màn hình Thuyết trình viên Độc lập (Presenter Console Mode)
- **Mở tab trên máy tính**: Nhấn phím `P` hoặc nút **Presenter** trên Header (mở đường dẫn có tiền tố `?mode=notes`).
- **Dùng Điện thoại làm Điều khiển từ xa (Remote Control)**:
  1. Quét **mã QR** hiển thị trên góc Header hoặc trong màn hình Presenter Console bằng camera điện thoại.
  2. Điện thoại của bạn lập tức trở thành tay cầm điều khiển không dây!
  3. Giao diện mobile được tối ưu riêng: nút bấm cảm ứng siêu to, hỗ trợ vuốt chạm (*Swipe Left/Right*), chữ kịch bản to rõ dễ đọc trên bục phát biểu.
  4. Mọi thao tác bấm *Next/Prev* trên điện thoại sẽ điều khiển màn hình máy chiếu lập tức theo thời gian thực.

### 3. Video Tư liệu Lịch sử (Archival Video Overlays)
- Tại **Slide 9** (Pearl Harbor) và **Slide 12** (Stalingrad):
  - Khi xem nội dung slide xong, nhấn **Next** (hoặc `Space` / `→`) để mở video tài liệu điện ảnh.
  - Video tự động phát với hiệu ứng màu phim Sepia cổ điển và khung tranh quân sự.
  - Khi xem xong, nhấn **Next** một lần nữa: video sẽ tự động mờ dần (*fade out*) và trôi êm ả sang slide tiếp theo.
  - Có thể bấm nút loa trên thanh tiêu đề để bật/tắt tiếng, hoặc bấm nút `✕` / phím `ESC` để quay lại nội dung slide.

### 4. Bảng Phím tắt / Keyboard Shortcuts

| Phím (Key) | Chức năng (Function) |
| :--- | :--- |
| `Space` / `→` / `PageDown` | **Tiến tới**: Chuyển slide tiếp theo / Phát video tư liệu / Mở bước tiếp theo |
| `←` / `PageUp` | **Lùi lại**: Quay lại slide trước / Đóng video tư liệu |
| `F` | **Toàn màn hình**: Bật / Tắt chế độ Fullscreen |
| `N` | **Ghi chú**: Bật / Tắt bảng Speaker Notes Overlay |
| `P` | **Presenter Console**: Mở tab điều khiển thuyết trình độc lập |
| `G` | **Tổng quan**: Mở lưới xem nhanh toàn bộ 20 slide (Slide Grid Overview) |
| `ESC` | **Đóng**: Đóng các bảng pop-up, đóng video tư liệu hoặc thoát toàn màn hình |

## 🚀 Cài đặt & Khởi chạy / Getting Started

### Yêu cầu Tiên quyết / Prerequisites
- Đã cài đặt [Node.js](https://nodejs.org/) (khuyến nghị phiên bản 18+ hoặc 20+).
- Trình quản lý gói `npm`, `yarn`, hoặc `pnpm`.

### Các bước Cài đặt / Installation

1. **Clone repository về máy**:
   ```bash
   git clone https://github.com/manfriendsss/ww2.git
   cd ww2
   ```

2. **Cài đặt các thư viện phụ thuộc**:
   ```bash
   npm install
   ```

3. **Khởi chạy máy chủ phát triển (Development Server)**:
   ```bash
   npm run dev
   ```
   Mở trình duyệt web và truy cập: `http://localhost:5173`

4. **Biên dịch bản chạy chính thức (Production Build)**:
   ```bash
   npm run build
   ```
   Các file tối ưu hóa sẽ được xuất ra thư mục `dist/`.
